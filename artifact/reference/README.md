# Numerical references

Each CSV is derived from a completed study used by the current manuscript.
`manifest.json` records original source paths/hashes and released hashes.
Only local workspace prefixes were removed from provenance strings. Numerical
columns were preserved. These compact references accompany runners and inputs;
new executions record their own full logs and lifecycle traces.

`hotspots.csv` uses 1/8 entries per page (the second table speedup column is
E=8). `cost_overhead_audited.csv` distinguishes the cumulative 181,707 cycles
from the old final-kernel-only field. `phase_boundary_summary.csv` includes
one explicitly infeasible deadline case with no performance estimate.
